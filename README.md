# 🔁 TikTok Repost Monitor

Telegram-бот для мониторинга репостов TikTok-аккаунта. Бот автоматически проверяет новые репосты через заданный интервал, уведомляет об изменениях и сохраняет историю в Excel-файл.

## ✨ Возможности

- 📥 Парсинг репостов TikTok через Playwright (реальный браузер)
- 📊 Сохранение данных в Excel (новые + удалённые репосты)
- 🗑 Обнаружение удалённых репостов
- ⏱ Настраиваемый интервал проверки прямо из Telegram
- 🤖 Telegram-бот с командами `/refresh`, `/status`, `/time`
- 🔁 Автоматический мониторинг в фоне

## 📋 Требования

- Python 3.10+
- Google Chrome или Chromium (устанавливается через Playwright)
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

## 🚀 Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/YOUR_USERNAME/tiktok-repost-monitor.git
cd tiktok-repost-monitor
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
playwright install chromium
```

### 3. Настроить конфигурацию

Откройте `config.py` и заполните его вашими данными:

```python
USERNAME = "tiktok_username"       # TikTok аккаунт для мониторинга
TELEGRAM_TOKEN = "ваш_токен"       # Токен от @BotFather
CHAT_ID = 123456789                # Ваш Telegram ID (узнать у @userinfobot)
PROXY = None                       # Опционально, для ограниченных регионов(работает только на бота телеграм): "socks5://user:pass@host:port"
INTERVAL_HOURS = 5                 # Интервал проверки по умолчанию (в часах)
```

### 4. Запустить бота

```bash
python tt.py
```

При первом запуске откроется браузер — **пройдите капчу в TikTok вручную**, после чего сессия сохранится в папке `browser_profile/` и при следующих запусках капча запрашиваться не будет.

## 📁 Структура файлов

```
tiktok-repost-monitor/
├── tt.py                  # Основной скрипт

```

## 🤖 Команды бота

| Команда | Описание |
|---------|----------|
| `/refresh` | Запустить проверку вручную |
| `/status` | Показать статус и время до следующей проверки |
| `/time` | Изменить интервал проверки |

## ⚙️ Настройка интервала

Используйте команду `/time` прямо в Telegram — доступны варианты от 30 секунд (для тестов) до 12 часов.

## 🐛 Частые проблемы

**Бот не видит репосты**
→ Откройте TikTok вручную в браузере и проверь, что вкладка "Репосты" у аккаунта открыта публично.

**Браузер не запускается**
→ Убедись что выполнил `playwright install chromium`

**Ошибка авторизации Telegram**
→ Проверь правильность токена в `config.py`
